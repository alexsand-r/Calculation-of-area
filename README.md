# 📐 Geometry Area Calculator  

This is a simple web application for calculating the area of various geometric shapes, including squares, circles, triangles. The project is built with **HTML**, **CSS**, and **JavaScript**.  

🔗 Live Demo: [Your GitHub Pages Link](https://alexsand-r.github.io/Calculation-of-area/)

## 🚀 Features  

✅ **Input Forms**: Allows users to enter the dimensions of different shapes.  
✅ **Area Calculation**: Calculates the area of shapes based on user input.  
✅ **Shape Selection**: Choose from different geometric shapes to calculate area.  

## 🛠️ Technologies Used  

- ![HTML](https://img.shields.io/badge/HTML-232F3E?style=for-the-badge&logo=html5&logoColor=E34F26) **HTML** – For building the structure of the web pages.  
- ![CSS](https://img.shields.io/badge/CSS-232F3E?style=for-the-badge&logo=css3&logoColor=1572B6) **CSS** – For styling the application.  
- ![JavaScript](https://img.shields.io/badge/JavaScript-232F3E?style=for-the-badge&logo=javascript&logoColor=F7DF1E) **JavaScript** – For handling the logic of shape area calculations.
